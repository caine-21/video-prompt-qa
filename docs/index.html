Design Decisions

→

Why 5 orthogonal dimensions, not a single score

Each dimension maps to a distinct failure mode. A single score hides which aspect to fix — this forces addressing the actual root cause.

→

Same system prompt across all providers

Scores must be comparable. If Claude gives 7/10 and Groq gives 4/10 on the same prompt, the gap is signal about model calibration — not prompt quality.

→

16 edge case fixtures, not automated tests

Evaluation is inherently subjective. The fixtures define boundary conditions — what the system must get right at the edges. They're the spec, not a test suite.
